# OOP Practice and Mini Projects

This repository contains C++ programs created for learning,
practice, and progressive project development.

## 🧠 Implementation Programs

### 🧾 Discount Calculator
**Folder:** `implementation/`

A simple console-based program that:
- Accepts item prices until checkout (`0` input)
- Calculates total bill amount
- Applies a **10% discount** if the bill exceeds **5000**
- Displays final payable amount

**Concepts used:**
- Loops (`do-while`)
- Conditional statements
- Input handling
- Basic arithmetic logic

### Product Discount Program (C++)

Menu-driven C++ program demonstrating **friend functions** and **OOP concepts** to calculate product price after discount.

### Concepts Used
- Classes & Objects  
- Friend Function  
- Menu-driven program  

### Run
```bash
g++ menu-driven-product-discount.cpp && ./a.out
```

Purpose: Practice **implementation-style problems** and logic building in C++.

## 📘 Mini Project

### 🎓 Student Management System
**Folder:** `mini-projects/`

A console-based Student Management System built using **C++ and OOP concepts**.

**Current features:**
- Add new student records
- Update complete student details
- Update CGPA with validation (0–10)
- Update hostel information
- Display student details using roll number
- Menu-driven interface
- Prevent Duplicate roll no

**Concepts used:**
- Classes and Objects
- Encapsulation
- Member functions
- Arrays of objects
- Input validation of Roll No. and CGPA using `numeric_limits`

🚧 **Status:** Incomplete – Work in Progress  
This project is being improved incrementally and will later include:
- STL containers (`vector`)
- File handling (save/load data)
- Modular structure (`.h` / `.cpp`)
- Additional features like delete and search
